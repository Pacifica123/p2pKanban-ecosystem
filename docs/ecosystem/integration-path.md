# Путь интеграции

## Решение

Инициирующий патч только кладёт направления рядом. Дальше они сближаются
ступенями, и каждая ступень обратима. Переход на следующую ступень — отдельная
карточка на доске, а не побочный эффект другого патча.

## Ступени

| № | Состояние | Что истинно | Как понять, что ступень пройдена |
|---|---|---|---|
| 0 | **Рядом** (инициирующий патч) | одно дерево, одна доска, один поток патчей; направления не связаны | каждое направление собирается из своего подкаталога так же, как из отдельного репозитория |
| 1 | **Видимые контракты** | контракты из [boundaries.md](boundaries.md) вынесены в `contracts/` с JSON Schema и общими фикстурами; направления проверяют себя по ним | изменение контракта ломает проверку у потребителя в том же патче |
| 2 | **Измеряемый дрейф** | корневая проверка сравнивает якоря abl и общие фикстуры с текущими файлами соседей | дрейф виден в отчёте `devctl start`, а не обнаруживается на хосте |
| 3 | **Выборочная установка** | метаустановщик в корне: скачать разом, развернуть выбранные направления, каждое — своим bootstrap | пользователь ставит только abl или только web одной командой и профилем |
| 4 | **Общий релизный ритм** | теги по направлениям (`web/v2.1.0`, `mobile/v2.1.0`, `abl/a17`, `devctl/v0.8.0`), матрица совместимости, CI с фильтрами по путям | релиз одного направления не требует релиза остальных, но совместимость записана |
| 5 | **Живая доска** | корневая доска синхронизируется с работающим узлом, devctl receipts двигают карточки | патч, применённый devctl, сам оставляет evidence на доске |
| 6 | **Общий код по необходимости** | общие пакеты появляются там, где контракт реализован трижды и расходится | дублирование уменьшилось без потери автономности направлений |

## Что остаётся неизменным на любой ступени

- любое направление можно взять и развернуть одно;
- корень можно удалить без поломки направлений;
- философия направления (Docker у web, его отсутствие у abl, Expo у mobile,
  стандартная библиотека у devctl) не приносится в жертву единообразию.

## Отложенное сознательно

- перенос истории коммитов исходных репозиториев в монорепозиторий;
- переключение канала обновления установленных web-узлов на новый репозиторий;
- слияние кодовых баз web, mobile и abl.

Каждый пункт записан на доске с причиной, почему не сейчас.
