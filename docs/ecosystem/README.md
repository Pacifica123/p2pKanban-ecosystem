# Метадокументация экосистемы

Здесь описано только то, что лежит **между** направлениями: зачем они вместе,
где проходят границы, как ими управлять и куда всё движется. Всё, что касается
одного направления, остаётся в его собственных `README.md` и `docs/` и здесь
не повторяется.

Актуальность документов всех направлений показывает
`python -B tools/ecosystem/docs_audit.py`: документы без даты, битые ссылки,
пропавшие пути, ADR, заменённые молча. Это отчёт, а не барьер: судьбу
документа решает патч его направления.

## Порядок истины

Если документы расходятся, верх берёт:

1. работающий код и файлы версий направления;
2. `README.md` и `docs/` самого направления — для всего, что внутри него;
3. этот каталог — для связей между направлениями;
4. `board/board.json` — для намерений и очереди работы (доска — план, а не факт);
5. исторические `PATCH_SUMMARY.md` и release notes.
