# Учебники p2pKanban

Дата: 2026-10-16.

Здесь будут два учебника и общий для них глоссарий. Как они пишутся, описано
в [методологии](../ecosystem/textbooks.md).

| Книга | Для кого | Состояние |
|---|---|---|
| Глоссарий (`glossary.md`) | для обеих книг | следующий шаг |
| Учебник разработчика (`developer/`) | человек-разработчик | после глоссария |
| Учебник пользователя (`user/`) | человек, впервые слышащий слово «p2p» | после мета-бутстрапера |

## Как читать

Ничего собирать не нужно. Откройте нужную книгу на GitHub или в любом
просмотрщике Markdown. Схемы (Mermaid и SVG) и рисунки GitHub показывает прямо
в тексте. Скриншоты лежат в релизе издания учебника, и учебник ссылается на
них прямыми ссылками, так что они тоже видны в тексте.

Главы читаются по порядку: каждая опирается на предыдущие. Карта маршрута —
в начале каждой книги.

## Как поправить рисунок

Схема в блоке `mermaid` правится как текст. Рисунок `figures/*.excalidraw.svg`
открывается на [excalidraw.com](https://excalidraw.com) (меню → Open), правится
мышкой и сохраняется обратно через Export image → SVG с включённым
«Embed scene». Изменённый файл приходит обычным патчем.

## Как выпустить новое издание

Издание нужно, только когда поменялись экраны, которые снимают скриншоты.

1. Снять скриншоты по [`shots.json`](shots.json). Команды для этого пока нет:
   UIX-раннеру web нужен шаг `screenshot` (карточка web на доске). До неё
   скриншотов в учебниках нет.
2. Создать GitHub Release с тегом `textbook-ГГГГ-ММ` и приложить к нему PNG,
   например `gh release create textbook-2026-11 shots/*.png`.
3. Патчем поменять тег в ссылках на скриншоты.

## Проверка

```bash
python -B tools/ecosystem/check_textbooks.py
```

Падает, если в этом каталоге появился растровый файл, сломалась ссылка или
скриншот не описан в `shots.json`. Подробно — в разделе 6 методологии.
