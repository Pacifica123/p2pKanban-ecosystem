## Вердикты сверки

| Вердикт | Когда |
|---|---|
| актуально | установленный коммит равен последнему коммиту `main`, менявшему каталог направления |
| устарело | установлен более старый коммит |
| изменено локально | в checkout есть незакоммиченные правки каталога |
| ожидайте APK | (mobile) в `mobile/` есть коммит новее последней завершённой сборки EAS |
| не установлено | ни реестр лаунчера, ни `status` направления не знают установки |
| не работает | `status` направления отвечает ошибкой или не по контракту |
| работает / остановлено | (с L2) ответ `status` направления; рядом — актуальна ли установка: её коммит против последнего коммита каталога в `main` |
| неизвестно | нет сети и кеша, или у направления ещё нет `launcher.json` |
