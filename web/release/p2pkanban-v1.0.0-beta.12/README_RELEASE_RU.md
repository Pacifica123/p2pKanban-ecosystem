# p2pKanban v1.0.0-beta.12

Исправляющий релиз для production-сборки beta.11 и обнаружения обновлений.

- Исправлены TypeScript и Rust compile blockers.
- Web определяет новый commit даже без живого host control plane.
- Запущенная revision отделена от Git HEAD рабочего checkout.
- Состояние bootstrap фиксирует фактически собранную версию.
- Devctl после push будит локальный UI-установщик.
