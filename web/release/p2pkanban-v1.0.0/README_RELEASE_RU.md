# p2pKanban v1

Единая версия web/backend/Android без каналов stable/dev/beta.

- Windows/ReviOS bootstrap больше не зависит от CRLF host-script.
- Остановленный Docker gateway сохраняет закреплённый порт узла.
- Android закрывает доску сразу, не ожидая sync, и обновляется с `versionCode 10`.
- Встроенная roadmap-доска актуализирует v1 и планы v2.

Полные изменения: `docs/product/v1.0.0-release-notes.md`.
