# p2pKanban v2.0.0

Исходный релиз web/backend. Запуск: `python bootstrap.py start`. Android обновляется отдельным патчем. Описание подготовки доверенного устройства, Markdown, интеграций и ограничений: [релизные заметки](../../docs/product/v2.0.0-release-notes.md).

Обновление базы добавляет миграцию 0019. Сначала резервная копия. Исходный пароль не переносится на новый узел; нужен собственный пароль. Подключение автономного узла пока относится к устройствам одного владельца, не к распределённому управлению всеми участниками.
