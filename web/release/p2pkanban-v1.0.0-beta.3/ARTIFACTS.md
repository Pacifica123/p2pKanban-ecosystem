# Состав релиза v1.0.0-beta.3

В GitHub Pre-release нужно приложить:

- `p2pkanban-v1.0.0-beta.3-bootstrap.zip`;
- `SHA256SUMS.txt`;
- последний `release-gates_*.zip`.

GitHub автоматически добавит архивы исходного кода по тегу.

Windows `.exe`, Linux AppImage, подпись контрольных сумм, SBOM и
мультиархитектурные контейнеры являются дополнительными, а не обязательными
артефактами beta.3.
