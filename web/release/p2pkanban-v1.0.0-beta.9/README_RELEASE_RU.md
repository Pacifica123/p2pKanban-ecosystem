# p2pKanban v1.0.0-beta.9

Этот ZIP обновляет web/backend до beta.9. Checklist roaming использует
независимые entity-delta: поздний полный снимок больше не удаляет, не заменяет
и не перезаписывает соседние пункты. Activity фиксирует только фактические
изменения и не создаёт ложное «Карточка перемещена» из-за чек-листа.

Совместимый Android-клиент: `1.5.0-mobile.7`.

## Установка

```bash
python bootstrap.py update --source-dir .
python bootstrap.py start --listen lan
```

Миграция `0015` выполняется автоматически и удаляет однозначно ложные legacy
`card.moved`, созданные full-snapshot roaming.

- изменить и удалить один пункт, не затронув соседний;
- убедиться, что checklist-действие не создаёт ложное перемещение карточки;
- проверить версии web и backend в боковой панели;
