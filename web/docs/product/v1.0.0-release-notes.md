# p2pKanban v1

Дата: 2026-08-23.

## Windows/ReviOS и Docker

- Устранено падение `bootstrap-init` с `set: illegal option -`: секреты теперь
  создаются inline-командой Compose, а не `.sh`-файлом из Windows checkout.
- Backend image дополнительно нормализует CRLF entrypoint при сборке.
- Bootstrap находит порт не только работающего, но и остановленного gateway,
  поэтому перезапуск ноутбука не превращает тот же Compose deployment в новый
  адрес узла.
- Изолированный Compose smoke создаёт собственный временный volume и не касается
  пользовательских PostgreSQL/secrets volumes.

## Android

- Восстановлена последняя рабочая mobile.9-база и переведена на общее имя v1.
- Выход с загружаемой доски больше не ждёт синхронизацию; системная и экранная
  кнопки используют один синхронный navigation controller.
- Начальная sync-задача стартует после navigation interaction и отменяется,
  если экран уже закрыт.
- `versionCode 10` позволяет установить v1 поверх mobile.9.

## Roadmap и версия

- Встроенная демонстрационная доска обновляет уже существующие seed-карточки,
  а не только создаёт новую доску для чистого аккаунта.
- В v2 запланированы rich text, приглашения и права, интеграции с GitHub,
  devctl и Obsidian; порядок отражён колонками и приоритетами карточек.
- Каналы stable/dev/beta отменены; v1 обозначает итог текущей сессии развития.
