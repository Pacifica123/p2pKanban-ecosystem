# Текст релиза p2pKanban v1.0.0-beta.3

Это заготовка для GitHub Pre-release. Русская и английская версии описывают
один и тот же набор возможностей и ограничений.

## Русская версия

```markdown
# p2pKanban v1.0.0-beta.3

Первый цельный beta-релиз p2pKanban с запуском одной командой.

p2pKanban — self-hosted local-first канбан-доска. Основной сценарий уже
работает: регистрация, рабочие пространства, доски, колонки, карточки,
перетаскивание, метки, чек-листы, комментарии, история, настройка внешнего
вида, локальное сохранение изменений и экспорт резервной копии.

## Главное в beta.3

- новый запуск через `python bootstrap.py`;
- PostgreSQL, роль, БД, backend и frontend создаются в Docker автоматически;
- `.env`, локальные Rust/Node/PostgreSQL и ручной SQL не нужны;
- секреты генерируются автоматически и остаются в закрытом Docker volume;
- свободный web-порт выбирается автоматически;
- добавлены команды `status`, `logs`, `stop` и защищённый `reset --yes`;
- выделен независимый `sync-core`;
- добавлены экспериментальные Nostr shadow mirror, Iroh transport adapter и
  Cloudflare Durable Object coordinator;
- документация выровнена с фактической архитектурой и переведена на русский.

## Быстрый запуск

Заранее нужны:

- Python 3.10+;
- запущенный Docker Desktop либо Docker Engine;
- Docker Compose v2.

После распаковки:

```bash
python bootstrap.py
```

На Windows можно использовать:

```powershell
py bootstrap.py
```

Bootstrap сам соберёт контейнеры, создаст БД, применит миграции и откроет
приложение. Остановка без удаления данных:

```bash
python bootstrap.py stop
```

## Важно

Это Pre-release. Общая работа пока опирается на Rust/PostgreSQL-координатор.
Nostr, Iroh и edge coordinator являются экспериментальными транспортами, а не
готовым бессерверным P2P-режимом. Полноценные mobile-клиент, conflict UI,
зашифрованное локальное хранилище и применение import-backup ещё не готовы.
```

## English version

```markdown
# p2pKanban v1.0.0-beta.3

The first cohesive p2pKanban beta with a one-command setup path.

p2pKanban is a self-hosted, local-first Kanban board. The main workflow is
available: accounts, workspaces, boards, columns, cards, drag and drop, labels,
checklists, comments, activity history, appearance settings, local change
storage, and backup export.

## Highlights

- one-command startup with `python bootstrap.py`;
- PostgreSQL, its role and database, the backend, and the frontend are created
  automatically in Docker;
- no `.env`, host Rust/Node/PostgreSQL, or manual SQL is required;
- secrets are generated automatically and kept in a private Docker volume;
- a free web port is selected automatically;
- `status`, `logs`, `stop`, and guarded `reset --yes` commands;
- a transport-neutral `sync-core`;
- experimental Nostr shadow mirror, Iroh transport adapter, and Cloudflare
  Durable Object coordinator;
- documentation aligned with the current architecture and localized into
  Russian.

## Quick start

Prepare:

- Python 3.10+;
- a running Docker Desktop or Docker Engine;
- Docker Compose v2.

After extracting the archive:

```bash
python bootstrap.py
```

On Windows, this command can be used instead:

```powershell
py bootstrap.py
```

The bootstrap builds the containers, creates the database, applies migrations,
and opens the application. Stop it without deleting data:

```bash
python bootstrap.py stop
```

## Important

This is a pre-release. Collaboration still relies on the Rust/PostgreSQL
coordinator. Nostr, Iroh, and the edge coordinator are experimental transport
foundations, not a finished serverless P2P mode. A production mobile client,
full conflict UI, encrypted local storage, and backup import execution are not
finished yet.
```
