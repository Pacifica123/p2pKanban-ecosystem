# Политика версий p2pKanban

Дата вступления в силу: 2026-08-23.

## Один номер — одна сессия развития

- Пользовательское имя текущей версии: `v1`.
- Машинная SemVer-форма для package manifests и Docker images: `1.0.0`.
- Следующая отдельная сессия подписки и разработки получает имя `v2`, затем
  `v3` и так далее.
- Major-номер фиксирует итог возможностей совместной сессии человека и LLM,
  а не обещание завершённости продукта.

## Непрерывная разработка

Каналов stable/dev/beta нет. `main` остаётся непрерывной линией разработки, а
каждый новый commit может быть предложен установленному web-узлу через UI
updater. Исторические имена `beta.N` и `mobile.N` сохраняются только в старых
release notes, миграциях и image tags, чтобы не терять происхождение данных.

Patch/minor-компоненты SemVer могут использоваться как технические номера
совместимости и исправлений внутри одной сессии, но не образуют отдельные
release-каналы и не заменяют пользовательское имя `vN`.
