# p2pKanban v1.0.0-beta.5

## Главное

- В настройках аккаунта появились три режима добавления пункта чек-листа:
  `Ctrl+Enter`, `Enter` и только кнопка `+`.
- Карточку можно открывать прежней боковой панелью или центральным плавающим
  окном. Настройка действует для аккаунта на всех досках.
- У доски появился собственный акцентный цвет. Колонки и карточки получают
  связанные оттенки: в тёмной теме карточка темнее колонки, в светлой —
  светлее.
- Новый фон `От акцента` строится из выбранного цвета. Смена акцента не
  заменяет уже установленный wallpaper.
- Информационная полоса доски над wallpaper получила тематическое
  затемнение или засветление и небольшое размытие подложки.
- Backup/import сохраняет пользовательский акцент, фон `От акцента` и
  wallpaper-изображение.

## Совместимость

Миграция `0011_account_workflow_and_accent_customization.sql` добавляет только
новые поля предпочтений и ограничения оформления. Для существующих аккаунтов
остаются прежние значения: `Ctrl+Enter` и боковая панель. Доски и wallpaper не
удаляются и не перезаписываются.
