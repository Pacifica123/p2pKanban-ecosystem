# p2pKanban v1.0.0-beta.4

## Главное

- На карточках доски появился прогресс по сумме всех пунктов чек-листов.
- У каждой доски появилась 84-дневная сетка продуктивности.
- В оформлении доски можно указать wallpaper-изображение по HTTP(S)-ссылке.
- Android автоматически подготавливает все доступные доски для удалённой
  local-first работы; ручное открытие каждой доски возле узла больше не нужно.
- Исправлены Android `crypto.getRandomValues`, перекрытие формы клавиатурой и
  неудобное расположение кнопки добавления карточки.
- Чек-листы включены в Android snapshot и зашифрованный roaming-журнал.

## Совместимость

Сначала обновляется основной p2pKanban до `1.0.0-beta.4`, затем отдельный
Android-проект до `1.3.0-mobile.4`. Старый APK не использует новые данные
чек-листов, но web/API остаются обратно совместимыми.

Миграция `0010_mobile_checklists_productivity_wallpapers.sql` не удаляет
пользовательские данные.
