# p2pKanban v1.0.0-beta.11

Beta.11 убирает фиксированный статус карточки: её состоянием теперь является
пользовательская колонка. Патч также чинит доверие к cross-client checklist
sync, перенос оформления через relay и восстановление web-сессии без 401 storm.

## Канбан-модель

- `status` и card-level `completedAt` удалены из HTTP, TypeScript, Rust,
  import/export и roaming-контрактов.
- Любое имя и число состояний задаются колонками. Перемещение карточки является
  единственным переходом состояния.
- Миграция физически удаляет старые колонки `cards.status` и
  `cards.completed_at`, чтобы хранилище также следовало модели «колонка =
  состояние» без скрытого второго источника истины.

## Синхронизация и оформление

- Backend одновременно публикует и принимает roaming-данные и параллельно
  опрашивает доски с ограниченной конкуренцией вместо последовательных relay
  timeout.
- Настройки оформления получили `board.appearance.put`, LWW-версию, outbox,
  echo guard и backfill уже настроенных досок.
- Android сохраняет оформление local-first и при недоступном LAN-узле отправляет
  его через relay.
- Слияние Android snapshot теперь выполняется по checklist/checklist-item и
  учитывает card/checklist/item tombstone, поэтому устаревший снимок узла не
  затирает новый пункт или удаление.
- Web повторно получает оформление открытой доски каждые 5 секунд.

## Web

- Один refresh singleflight обслуживает параллельные 401. При окончательной
  потере сессии запросы блокируются, query cache очищается и интерфейс один раз
  возвращается к входу без повторяющегося потока запросов.
- Card details получает CSS variables выбранной board theme, хотя drawer
  находится вне DOM-поддерева доски.

## Android 1.5.0-mobile.9

- В деталях карточки показано имя колонки без отдельного status selector.
- Приоритет стал одной плоской строкой из 0–4 звёзд.
- Заголовок конкретного чек-листа получил больший визуальный вес, а контейнеры
  чек-листов, комментариев и действий стали легче и без лишнего стекла.
- Card details наследует palette, custom accent и поверхности текущей доски.

## Версии

- web/backend: `1.0.0-beta.11`;
- Android: `1.5.0-mobile.9` (`versionCode 9`);
- bootstrap updater остаётся на совместимом control-plane контракте beta.10.

## Обновление

На уже установленной beta.10 loopback web-плашка может принять новый commit,
собрать beta.11, сделать PostgreSQL dump и переключить контейнеры на прежнем
порту. CLI `python bootstrap.py update` остаётся аварийным и диагностическим
путём. Первое получение самого updater всё ещё требует, чтобы текущая beta.10
действительно была запущена с рабочим host control plane.
