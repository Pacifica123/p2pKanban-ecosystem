# p2pKanban v1.0.0-beta.10

Beta.10 добавляет локальные напоминания, сближает Android с web по оформлению и
переносит безопасное обновление self-host узла в UI без выдачи Docker socket
контейнерам.

## Web и bootstrap

- Последний commit `main` проверяется локальным host control plane; web-плашка
  показывает первую строку commit message и скрывается только до следующего SHA.
- После согласия скачивается immutable archive выбранного SHA. Если `main`
  успела измениться, update не подменяет принятую версию и просит проверить снова.
- Стабильный gateway владеет внешним портом, пока versioned backend/web
  собираются и заменяются. Overlay либо maintenance page остаются на том же URL.
- До переключения создаётся `pg_dump`, старые images получают rollback tags, а
  после readiness сравниваются counts основных пользовательских сущностей.
- Docker socket не монтируется в приложение. Изменяющие запросы доступны только
  на `127.0.0.1:8765` с точным loopback Origin и локальным random token.
- Bootstrap сначала принимает фактический порт работающего Compose stack по
  labels. Закреплённый занятый порт больше не вызывает молчаливый сдвиг узла.

## Напоминания

- На карточку можно назначить одно floating-local напоминание.
- Web хранит его по `userId` и показывает toast/Browser Notification, пока
  вкладка открыта.
- Backend, PostgreSQL schema и roaming payload не получают reminder data.

## Android 1.5.0-mobile.8

- One-shot системные notification по локальным дате и времени с deep link на
  карточку, пересборкой после активации в новом timezone и очисткой при sign-out.
- Тема, плотность, reduce motion, board palette, custom accent, wallpaper,
  плотность колонок и настройки preview используют те же backend endpoints, что
  web. CSS gradient адаптируется к flat color без перезаписи серверного значения.
- Старые local snapshots 1–3 мигрируют в schema 4 с безопасным preset `system`.
- APK source self-update не имитируется: следующий этап требует CI с APK/AAB,
  той же signing identity и Android installer consent либо Expo OTA runtime.

## Проверить перед stable

- Docker smoke UI update → maintenance → reload на Windows и Linux;
- rollback и чтение `pg_dump`, сохранение всех core counts и прежнего порта;
- Android notification на реальном Android 13+, permission deny/grant, reboot и
  смена timezone;
- appearance web → Android и Android → web;
- reminder isolation между двумя аккаунтами и двумя устройствами.
