# Доска проекта в web (`p2p-kanban-project-board/1`)

- Дата: 2026-10-17, патч `2026-10-17-web-project-board`
- Контракт: `contracts/project-board/1/` в корне монорепозитория; решение — E-ADR-003 экосистемы
- Заменяет: seed «P2P Planner roadmap / План работ по проекту» (удалён)

## Что видит человек

В боковой панели пункт **«Доска проекта · чтение»** (`/project-board`). Это доска, на
которой p2pKanban ведёт свою разработку: колонки, карточки, метки, чек-листы и
комментарии, без кнопок изменения. Над доской строка «Ревизия N · патч · откуда»
(«из сборки узла» или «с GitHub (main)») и пояснения, если сборка отстала, GitHub
недоступен или у одной ревизии две разные доски.

## Почему не seed

Seed создавал обычное пространство и доску по имени на каждом узле. С двумя узлами и
телефоном это давало несколько досок с одним именем, разными UUID и разными ключами
доски. Доска проекта теперь не попадает в PostgreSQL, relay, `web-node-link/1` и
привязку устройства, поэтому дублироваться нечему. Пространство «P2P Planner roadmap»,
которое seed создал раньше, остаётся обычными данными пользователя: его можно
архивировать вручную, узел его не трогает.

## Узел

| Что | Где |
|---|---|
| копия доски в сборке | `backend/assets/project-board.json` (вкомпилирована, `include_bytes!`); обновляет `python -B tools/ecosystem/project_board.py vendor web` из корня |
| проверка GitHub | при запуске и раз в час (после ошибки — через 5 минут) `board/board.json` ветки `main` монорепозитория; `P2PKANBAN_PROJECT_BOARD_UPSTREAM=off` выключает, другой `https://…` — меняет адрес |
| выбор | старшая `boardRevision`; негодный ответ GitHub не вытесняет последнюю годную доску |
| маршруты | `GET /api/v1/project-board` (байты доски, `ETag` = sha256, `304` на `If-None-Match`, заголовок `x-p2p-kanban-project-board`), `GET /api/v1/project-board/summary`; без входа |
| код | `backend/src/modules/project_board.rs`, тесты `backend/tests/project_board_node.rs` (векторы контракта) |

Заодно `main.rs` ставит процессный крипто-провайдер rustls (ring): reqwest собран с
`rustls-no-provider`, и без провайдера любое создание HTTP-клиента в узле паникует.

## UI

`frontend/src/features/projectBoard/` — страница, разбор доски общим импортёром
`parseBoardBundleText`, подписи источника. Тесты:
`src/test/unit/features/projectBoard/`, `src/test/integration/features/projectBoard/`.

## Приёмка на хосте

1. Пересобрать узел, открыть «Доска проекта»: ревизия совпадает с `board/board.json`
   в `main`, источник «с GitHub (main)» или «из сборки узла».
2. Подключить второй узел и телефон: новых пространств и досок не появилось.
3. Выключить сеть узла и перезапустить: доска из сборки, пояснение «GitHub не проверен».
