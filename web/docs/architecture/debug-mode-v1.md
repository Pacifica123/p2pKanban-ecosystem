# Режим отладки в web UI

Патч `2026-10-17-web-debug-mode`. Продолжение [error-details-v1](error-details-v1.md):
тот же журнал клиента в памяти, но его видно в реальном времени, он подробнее и
переживает перезагрузку страницы. Тот же режим есть в mobile и abl, выгрузка
одинаковой формы.

## Что видит человек

Боковое меню → «Настройки» → **«Журнал отладки»** (`/settings/debug`):

- кнопка «Включить режим отладки» (переключатель хранится в `localStorage`
  этого браузера; в меню рядом с пунктом пометка «включён»);
- строки идут по мере работы, окно прокручивается вниз; «Пауза»;
- «Всё» / «Ошибки»; «Прошлая загрузка» — хвост журнала до перезагрузки страницы;
- «Скопировать» — Markdown в буфер обмена (на узле по http без HTTPS — через
  запасной путь `copyText`), «Сохранить .md» — файл
  `p2pkanban-web-debug-<время>.md`.

## Что меняет включённый режим

| | Выключен | Включён |
|---|---|---|
| строк в памяти | 200 | 5000 |
| что пишется | запросы к API с временем ответа, ошибки узла, `console.warn/error`, необработанные ошибки, сеть браузера (online/offline), вкладка скрыта/на экране, узел не принял изменение доски | плюс смена страниц, отправка очереди изменений доски по шагам |
| хранится | ничего | последние 500 строк без секретов в `localStorage`, раз в 3 с |

Подробные строки собираются только во включённом режиме
(`trace(source, () => текст)` в `src/shared/errorReport/journal.ts`).

## Что не попадает в журнал

- пароли, токены, JWT, `nsec`, ключи досок — каждая строка при показе, выгрузке
  и сохранении проходит `redact` из [error-report/1](../../../contracts/error-report/1/SPEC.md);
- тексты карточек: строки `board` называют id, вид операции и числа.

## Журнал узла

Этот режим — журнал браузера. Журнал самого web-узла (Rust) по-прежнему
смотрят командой `python bootstrap.py logs` или `docker logs`; связь между ними —
`errorId` в ответах 5xx.

## Проверка

- `npx vitest run src/test/unit/shared/debugJournal.test.tsx` — режим, ёмкость,
  вырезание секретов на экране, Markdown;
- в браузере: «Журнал отладки» → включить → открыть доску, передвинуть карточку,
  выключить Wi-Fi и включить → строки `api`, `nav`, `net`; перезагрузить страницу →
  «Прошлая загрузка».
