# Проверка приёмки в web UI

Отладочная кнопка «Настройки → Проверка приёмки» (`/settings/acceptance`),
патч `2026-10-17-web-acceptance-check`. Это уровень C из
[плана автоприёмки экосистемы](../../../docs/ecosystem/self-acceptance.md):
собранный web UI на настоящем узле под настоящим аккаунтом делает то, что
сделал бы человек, и отдаёт отчёт `p2p-kanban-acceptance-report/1`.

## Устройство

- `src/features/acceptance/webSteps.ts` — шаги. Каждый вызывает те же функции
  API-слоя (`features/*/api`), что и экраны, поэтому прошедший шаг означает
  прошедший пользовательский путь. Порядок: окружение → сеанс и лимит опроса →
  тестовые данные → карточки, чек-листы, комментарий длиннее 256 байт, метка,
  активность, удаление → «Встречная доска» → экспорт и импорт копией →
  подробности ошибки 404 → кольцо и канал обновления → темы → уборка.
- `runner.ts` — выполняет шаги по очереди: исключение — FAIL с текстом ошибки
  (для `ApiError` — метод, путь и статус); шаг, чей предшественник из `needs`
  не прошёл, — SKIP с его именем. Кнопка «Остановить» пропускает оставшиеся.
- `report.ts` — отчёт: Markdown для человека, затем маркер и канонический JSON
  (`canonical` и `redact` из `shared/errorReport/report.ts`). «Скопировать
  отчёт» использует тот же обход `copyText`, что «Скопировать подробности»
  (узел по http в LAN не даёт `navigator.clipboard`); «Сохранить .md» скачивает
  файл.

## Данные

- Личное пространство «Приёмка p2pKanban» находится по имени или создаётся.
- Доска прогона «Проверка web <время> · <id>» и её импортированная копия
  удаляются в конце.
- «Встречная доска» остаётся: каждая проверка web оставляет на ней карточку
  `web · …` с пунктом «Отметит Android» и отмечает пункт «Отметит web» на
  последней карточке `android · …`. Хранятся пять последних карточек web.
- Кнопка не создаёт кольцо, не переносит доверие, не завершает сеансы и не
  запускает обновление узла: эти шаги только читают состояние.

## Проверка

- `src/test/unit/features/acceptance/acceptance.test.ts`: правила runner,
  формат отчёта и полный прогон шагов против узла в памяти, включая встречную
  проверку двух прогонов.
- `python -B tools/check_acceptance_button.py` — маршрут, пункт меню и тест на
  месте.
