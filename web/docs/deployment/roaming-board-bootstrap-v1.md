# Запуск независимой синхронизации доски

Bootstrap-профиль включает Nostr bridge автоматически. Он создаёт и сохраняет
в Docker volume два дополнительных секрета:

- Nostr secret key транспортной реплики;
- master key, из которого выводятся отдельные ключи досок.

Существующие PostgreSQL, JWT-секреты и пользовательские данные не заменяются.

## Настройка реле

По умолчанию используются три публичных WSS-реле и требуется подтверждение
двух. Список можно заменить перед запуском:

```bash
export P2PKANBAN_NOSTR_RELAYS='wss://relay-1.example,wss://relay-2.example,wss://relay-3.example'
export P2PKANBAN_NOSTR_MIN_RELAY_ACKS=2
python bootstrap.py start
```

Для автономности нельзя настраивать единственный relay. Рабочая конфигурация
должна содержать минимум три независимых адреса.

## Первичная привязка Android

Телефон должен один раз увидеть backend, войти и открыть нужную доску. После
получения capability и первой успешной публикации можно выключить компьютер:
Android продолжит применять операции локально и обмениваться ими через relay
set.

Когда backend снова запустится, `roaming` worker:

1. прочитает события каждой доски;
2. применит победившие версии полей к PostgreSQL;
3. отправит через durable outbox изменения, сделанные в web-клиенте.

Проброс портов, Tailscale и общая Wi-Fi-сеть после привязки не нужны.

## Проверка

В логах backend должны появиться оба worker без ошибок подключения. Статус
транспортов доступен через авторизованный endpoint:

```text
GET /api/v1/sync/transports/status
```

Для практического теста откройте доску в Android, выключите компьютер, создайте
и переместите карточку, затем включите компьютер. После запуска bridge та же
карточка должна появиться в web-клиенте.
