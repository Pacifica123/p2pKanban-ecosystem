# p2pKanban Android 1.5.0-mobile.8

Совместимая версия узла: `1.0.0-beta.10`.

## Новое

- Одно локальное Android-напоминание на карточку с быстрыми вариантами времени.
- Уведомление открывает доску и нужную карточку.
- Напоминания сохраняют локальные компоненты даты/времени, перестраиваются при
  смене часового пояса после активации приложения и удаляются при выходе.
- Тема приложения, плотность и уменьшение движения синхронизированы с web.
- На доску перенесены web-палитры, custom accent, wallpaper, плотность колонок,
  режим превью и переключатели описания, дат и checklist-прогресса.
- Image wallpaper загружается по `http(s)` URL. Web CSS gradient адаптируется к
  плоскому цвету, при этом серверное значение не переписывается.

## Миграция

- Локальная схема snapshot поднята до `4`; снимки версий 1–3 получают безопасное
  оформление `system` без потери карточек или очереди операций.
- Добавлен `expo-notifications`; APK нужно пересобрать через `npm run apk`.
- Android `versionCode` поднят до `8`.

## Граница обновления APK

В клиенте нет фиктивного «обновить из source». Для настоящего обновления нужен
заранее собранный APK, та же signing identity и подтверждение Android installer.
Это оставлено будущему GitHub Release/CI или совместимому Expo OTA runtime.
