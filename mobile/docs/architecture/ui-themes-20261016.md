# Темы приложения (2026-10-16)

Mobile реализует словарь экосистемы `p2p-kanban-ui-themes/1`
(`docs/ecosystem/ui-themes.md` в корне монорепозитория): четыре темы интерфейса
самого приложения. Прежние палитры «светлая/тёмная» удалены.

| id | Название | Схема |
|---|---|---|
| `graphite` | Графит (по умолчанию) | тёмная |
| `lemon` | Лимон | светлая |
| `azure` | Лазурь | светлая |
| `silver` | Серебро | светлая |

- Значения цветов — `src/app/uiThemes.ts`, дословная копия словаря.
  `src/app/theme.ts` сводит их к `AppColors`: `accent` — заливка (accentStrong
  словаря), `accentText` — ссылки и выбранный пункт, `onAccent` — текст на
  заливке, `danger/success/warning` — читаемые на surface варианты (`*Text`),
  `dangerSoft` смешан из `danger` и `surface`.
- Выбор хранится в AsyncStorage под ключом `p2p-kanban.ui-theme`, не привязан к
  сеансу и узлу и не синхронизируется (`src/app/UiThemeProvider.tsx`). Он не ждёт
  сети: экран «Настройки» переключает тему сразу.
- Поле `appTheme` в настройках пользователя на узле mobile больше не читает и не
  меняет; узел и старые клиенты работают как прежде.
- Пресет доски `system` берёт цвета текущей темы приложения; именованные пресеты
  досок не изменились.
- versionCode не меняется: 26 уже поднят патчем 2026-10-16-mobile-ui-freeze, оба изменения
  входят в один новый APK.
