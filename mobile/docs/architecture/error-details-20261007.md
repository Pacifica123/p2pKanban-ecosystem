# «Скопировать подробности» на телефоне

Реализация контракта [error-report/1](../../../contracts/error-report/1/SPEC.md)
в mobile (патч `2026-10-07-mobile-error-details`). versionCode 25.

## Что видит человек

- У каждого сообщения об ошибке (`InlineNotice` с `tone="danger"`), у экранов
  «История/Пространства/Доски недоступны», «Доска не сохранена на устройстве»
  и у ошибок подключения устройства есть кнопка **«Скопировать подробности»**.
- Текст уходит только в буфер обмена (`expo-clipboard`) и только по нажатию;
  его вставляют в сообщение.

## Что в тексте

- `Программа: mobile 2.1.0 · сборка 25 · коммит <40 hex>` — версия APK,
  versionCode и коммит монорепозитория, из которого собран APK;
- `Узел: web … · сборка … · коммит …` — по заголовку `x-p2p-kanban-node`
  последнего ответа узла. Узел без заголовка (старше `2026-10-07-web-error-details`)
  даёт отчёт без строки «Узел», и это тоже видно. Так в одном отчёте видно
  смешение версий: старый APK против нового узла или наоборот;
- последний неудачный запрос (метод, путь, статус, `errorId` узла, тело ответа)
  и до 50 последних строк журнала из памяти (запросы к узлу,
  `console.warn/error`, необработанные ошибки JS);
- токены, пароли, ключи `nsec`, ключи досок вырезаны по правилам контракта.

## Коммит в APK

`npm run apk` берёт коммит из `git rev-parse HEAD` (или `P2PKANBAN_SOURCE_REVISION`)
и передаёт его как `EXPO_PUBLIC_SOURCE_REVISION`; Expo вписывает его в JS-бандл.
В EAS то же делает `eas-build-post-install` (`EAS_BUILD_GIT_COMMIT_HASH` →
`.env.local`, файл в `.gitignore`). Без git и без переменной коммит «неизвестен».

## Патч сборки

В «Настройках» под строкой «Android-клиент» стоит «Собран из патча:
патч N · <patchId>». Правило общее для клиентов:
`board/README.md`, «Номер патча в версии клиентов».

`scripts/build-patch.mjs` берёт `EXPO_PUBLIC_PATCH_ID`/`P2PKANBAN_PATCH_ID` и
`…_PATCH_REVISION`, затем `BUILD_PATCH.json` в `mobile/`, затем
`board/board.json` непосредственно над `mobile/`. `npm run apk` и
`eas-build-post-install` передают пару как `EXPO_PUBLIC_PATCH_ID` и
`EXPO_PUBLIC_PATCH_REVISION`, и Expo вписывает её в бандл, как коммит.
EAS загружает весь монорепозиторий, поэтому доска над `mobile/` там есть.
«Скопировать подробности» номер не несёт: это поле контракта error-report/1.

## Проверка

- `npx jest src/shared/errorReport` — векторы `contracts/error-report/1`,
  сборка отчёта из ответа узла 500 с `errorId`, сетевая ошибка, пустой экран;
- на телефоне: выключить узел → «Пространства недоступны» → «Скопировать
  подробности» → вставить в заметку: есть «сборка 25», коммит и «нет ответа».
