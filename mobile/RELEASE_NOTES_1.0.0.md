# p2pKanban Android v1

Совместимая версия узла: `1.0.0`.

## Навигация во время синхронизации

- Кнопка в заголовке и системная кнопка Android закрывают доску немедленно,
  не ожидая загрузки coordinator/relay snapshot.
- Начальная фоновая синхронизация откладывается до завершения анимации перехода;
  если пользователь сразу уходит, ещё не запущенная работа отменяется.
- Уже сохранённые локальные операции не теряются и будут отправлены текущим
  фоновым процессом либо при следующем открытии доски.

## Версия

- Пользовательская линия mobile.9 объединена с web/backend под именем `v1`.
- `versionName` и package version: `1.0.0`.
- Android `versionCode`: `10`, поэтому APK устанавливается поверх mobile.9.
- Каналы stable/dev/beta удалены; дальнейшая разработка продолжается внутри
  версий-сессий `vN`.
