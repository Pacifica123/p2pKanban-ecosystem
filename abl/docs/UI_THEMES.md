# Темы приложения

abl реализует словарь экосистемы `p2p-kanban-ui-themes/1`
(`docs/ecosystem/ui-themes.md` в корне монорепозитория): Графит (`graphite`, по
умолчанию, тёмная), Лимон (`lemon`), Лазурь (`azure`), Серебро (`silver`).
Прежняя тёмно-синяя палитра с фиолетовым свечением удалена.

- Цвета — `src/themes.css` (переменные `--ui-*`, дословная копия словаря);
  `src/styles.css` больше не содержит цветовых литералов, кроме одной тени.
- Тема выбирается в шапке окна (Theme) и применяется атрибутами `data-ui-theme`
  и `data-ui-scheme` на `<html>`. CSP не меняется: только классы и CSS-файлы.
- Выбор пока не переживает перезапуск: хранилища браузера во фронтенде
  запрещены проверками A07–A09, а долговременное состояние живёт за границей
  Rust core. Запоминание темы через Rust core — отдельная карточка на доске.
- Rust core, схема SQLite, протокол и упаковка не меняются.
