# Режим отладки в abl

Патч `2026-10-17-abl-debug-mode`. Продолжение [ERROR_DETAILS.md](ERROR_DETAILS.md):
тот же журнал WebView в памяти, но его видно в реальном времени и он подробнее.
Тот же режим есть в mobile и web; выгрузка в Markdown одинаковой формы.

## Что видит пользователь

Кнопка **«Журнал отладки»** в шапке окна (или Ctrl+Shift+L) открывает панель:

- «Включить режим отладки» — в шапке пометка «· вкл»;
- строки идут по мере работы, панель прокручивается вниз; «Пауза»;
- «Всё» / «Ошибки»;
- «Скопировать .md» — журнал в буфер обмена в Markdown («# p2pKanban: журнал отладки»,
  программа, платформа, строки). Если буфер WebView недоступен, текст показан в поле.

## Что меняет включённый режим

| | Выключен | Включён |
|---|---|---|
| строк в памяти | 200 | 5000 |
| что пишется | каждый вызов desktop API с временем ответа, ошибки, `console.warn/error`, сеть (online/offline), окно скрыто/на экране | плюс выбранные пространство, доска и карточка (id) |

Подробные строки собираются только в режиме (`trace(source, () => текст)` в
`src/shared/errorReport/journal.ts`).

## Чего в abl нет и почему

- **Режим не переживает перезапуск, хвоста прошлого запуска нет.** Фронтенд abl не
  хранит ничего долговечного вне границы Rust-репозитория (проверки A07–A09 запрещают
  `localStorage`). Mobile и web хранят хвост 500 строк. Чтобы abl сделал так же,
  нужна нативная команда, которая пишет хвост в профиль через Rust; это отдельный
  шаг, если хвост понадобится. Пока при зависании скопируйте журнал до перезапуска.
- **Сохранения файла нет**, только копирование: WebKitGTK в Tauri не скачивает
  `blob:`-ссылки без отдельной нативной команды.
- Строки Rust-процесса в панель не попадают (он почти ничего не пишет, только stderr).

## Что не попадает в журнал

Пароли, токены, JWT, `nsec`, ключи досок вырезаются `redact` из
[error-report/1](../../contracts/error-report/1/SPEC.md) при показе и копировании.
Тексты карточек не пишутся: только id, вид вызова и числа.

## Проверка

- `node tools/check_debug_mode.mjs` — ёмкость, ленивые строки, Markdown без секретов;
- `python3 -B tools/check_a07.py` (и a08, a09) — фронтенд по-прежнему ничего не хранит сам;
- на Arch: «Журнал отладки» → включить → открыть доску, отключить сеть →
  строки `desktop … за N мс`, `nav`, `net`; «Скопировать .md» → вставить в файл.
